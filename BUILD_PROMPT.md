## 2. ИЗВОРИ НА ПОДАТОЦИ (проверени во пракса до 28.10.2026)

### 2.1 Mozzart (квоти) — стандардна кладилница
База: `https://www.mozzartbet.mk`
- `POST /betOffer2` — body: `{"date":"all_days","sort":"bytime","pageSize":50,"offset":N,"sportIds":[2],"search":"","matchTypeId":0}` → листа натпревари; страничи со offset 0,50,100… додека не дојде празно. Филтрирај по `competition.id`. Поле `participants[0]`=домаќин, `[1]`=гостин, `startTime` (ms epoch).
- `GET /getAllGames` → `["2"]` = кошарка; земи го објектот со `name == "Комплетна понуда"` → `subgameIds` (дедупликирај).
- `POST /getBettingOdds` — body: `{"matchIds":[...до 30], "subgames":[...subgameIds]}` → секој натпревар има `kodds` (речник). Секој kodd: `subGame.gameShortName`, `subGame.subGameName` (`помалку`/`повеќе`, `1`/`2`), `specialOddValue` (линија), `value` (квота).
- **ВАЖНО:** ако се праќа `subgames: []` → нема kodds. Мора полната листа.
- ID на натпревари (competition.id): NBA=23 · NBA Players=11940 · Euroleague=26 · Euroleague Players=8578 · Eurocup=1147 · Eurocup Players=11924.
- Кодови на пазари: `кт. хен.` хендикеп · `хен. 1п` хендикеп 1. полувреме (игнорирај) · `вп` тотал · `впт1`/`впт2` тимски тотал домаќин/гостин · `идп` поени играч · `мбпи`/`вбпи` докупени ±2 · `ива` асистенции · `ивс` скокови · `ипса` П+С+А.
- Главна линија = онаа со квоти ~1.90/1.90 (или 1.85/1.85 за тимски); останатите се докупени.
- **Познат проблем:** играчките пазари за NBA понекогаш се објавуваат доцна (попладне се празни, вечер се појавуваат). Скриптата мора да може да се пушти повторно.
- Од прелистувач работеше преку fetch од mozzartbet.mk таб. Од Python: пробај `requests` со `User-Agent` како прелистувач, `Origin`/`Referer: https://www.mozzartbet.mk`. Ако блокира → документирај во PLAN.md и предложи решение (пр. Playwright).

### 2.2 Евролига / Еврокуп (официјални, бесплатни)
- Статистика: `https://feeds.incrowdsports.com/provider/euroleague-feeds/v3/competitions/{E|U}/statistics/{players|teams}/{traditional|opponentsTraditional|advanced}?seasonMode=Single&limit=50&seasonCode={E2026|U2026}&statisticMode=perGame`
- Распоред: `https://feeds.incrowdsports.com/provider/euroleague-feeds/v2/competitions/{E|U}/seasons/{E2026|U2026}/games?teamCode=XXX` (без teamCode = сите). Поле `date` е ISO UTC, `home`/`away` со `code`, `name`, `score`; `round.round`.
- Box score: `https://live.euroleague.net/api/Boxscore?gamecode=N&seasoncode={E2026|U2026}` → минути, поени, скокови, асистенции, тројки по играч.
- Постои PyPI пакет `py-euroleague` — провери дали е корисен, но предност имаат директните endpoints погоре (веќе проверени).
- **DvP (одбрана по позиција) за Евролига/Еврокуп НЕ постои бесплатно готово** → го пресметуваме сами од box score (види 3.1).

### 2.3 NBA
- Пакет `nba_api` (бесплатен, официјален stats.nba.com): box scores, advanced (USG%, AST%, REB%), team four factors, opponent stats, lineups, on/off.
- Резерва: basketball-reference.com (табели, `pandas.read_html`), почитувај rate limit (≥3 сек меѓу барања).
- Резултати во живо/распоред: `nba_api` scoreboard.

### 2.4 Повреди / состави
- NBA: официјален injury report PDF (`ak-static.cms.nba.com/referee/injury/Injury-Report_YYYY-MM-DD_HH_MMPM.pdf`) — парсирај со `pdfplumber`. Резерва: ESPN injuries.
- Евролига/Еврокуп: официјален injury report на euroleaguebasketball.net (вести) + box score од последното коло (кој НЕ играл = DNP).
- **Правило:** статус „questionable/GTD/се надеваат" во Евролига/Еврокуп = **смета дека игра**. Во NBA: Q = 50/50 → изборот добива ознака `ЗАВИСИ_ОД_СОСТАВ`.
- Повредата се класифицира: **НОВО отсуство** (играл во последните 3 натпревари, сега OUT) vs **СТАРО** (не играл последните 3+) — само новото носи предност.

## 3. ПАРАМЕТРИ

### 3.1 ТИМСКО НИВО (прво)
За секој тим, сезона + последни 5 натпревари (**сортирани по датум**), дома/гости одделно:
| Параметар | Формула / извор | Зошто |
|---|---|---|
| Поседи (pace) | FGA − OREB + TOV + 0.44×FTA (просек двата тима) | колку „простор" има за поени |
| ORtg / DRtg | поени / поседи × 100 | ефикасност без влијание на темпото |
| ORtg/DRtg прилагодени | корекција за јачина на противниците (SRS-стил итерација) | лесен распоред лаже |
| Four Factors (напад И одбрана) | eFG% = (FGM+0.5×3PM)/FGA · TOV% = TOV/поседи · OREB% · FT Rate = FTA/FGA | ~40/25/20/15% од победата |
| DvP по позиција | просек поени/скокови/асистенции што тимот ги ДОЗВОЛУВА по позиција (PG/SG/SF/PF/C), наспроти лигин просек (%) | „кој тим пушта што" |
| Дозволени асистенции | асистенции на противникот / противнички кошеви | switch-одбрана = малку ast |
| Дозволени скокови | противнички OREB% | box-out |
| Дозволени тројки | противнички 3PA rate, 3P% | варијанса |
| Форма | последни 5: поени за/против, W-L, ATS ако има | моментум |
| Одмор / патување | B2B, денови одмор, km патување (за NBA) | умор |
| H2H | последни N средби, тежина 60% на последните 2 | стил на средба |
| Мотивација | серија порази/победи, пласман, дерби, последен пред пауза, тим со 5+ победи по ред | ризик |

**DvP за Евролига/Еврокуп (сами пресметуваме):** позицијата на играч се зема од официјалниот профил; ако нема → од улогата (најмногу асистенции = PG, највисок/најмногу скокови = C). За секој одигран натпревар: збир по позиција што противникот го постигнал против тимот → просек → % наспроти лигата.

### 3.2 ИГРАЧКО НИВО (потоа)
| Параметар | Формула | Зошто |
|---|---|---|
| Минути | последни 5 по датум + сезона; стартер/клупа | **најважен** влез |
| USG% | 100×((FGA+0.44×FTA+TOV)×(ТимМин/5)) / (Мин×(ТимFGA+0.44×ТимFTA+ТимTOV)) | колку топки завршуваат кај него |
| AST% | AST / (((Мин/(ТимМин/5))×ТимFGM) − FGM) | колку од соиграчките кошеви ги асистира |
| REB% / OREB% / DREB% | скокови / достапни скокови додека е на терен | скокач или не |
| По минута (per-36) | поени, ast, скокови, тројки, слободни | основа за проекција |
| Фаули на 36 | PF×36/Мин | ризик од седење |
| Без соиграч X | неговите бројки во натпревари кога X бил DNP (од box score) | **проверка „кој презема"** |

**Пренасочување на usage (кога играч е OUT):**
`нова_USG(Y) = USG(Y) + USG_отсутен × (USG(Y)×Мин(Y)) / Σ(USG×Мин на преостанатите)`
Минутите на отсутниот одат кај **иста позиција** првенствено (тежина 70%), останатото пропорционално. Ако постојат натпревари без X → реалните бројки имаат предност над формулата (тежина 60/40).

## 4. МОДЕЛ (редослед на пресметка)
1. **Проекција на тим:** поседи = просек(pace А, pace Б) прилагоден · поени_А = поседи × (ORtg_А + DRtg_Б)/2 /100 · корекција дома (+~2 NBA, +~3 Евролига, +~4 Еврокуп — калибрирај од податоци).
2. **Сценарио на натпреварот:** очекувана разлика → ризик од голема разлика (blowout) → корекција на минути (фаворит: стартери −10–15% мин ако разлика >15; губитник: беците ПОВЕЌЕ шутови).
3. **Проекција на играч:** минути × по-минута × матчап множител (DvP) × usage множител (отсуства).
4. **Распределба:** поени ~ нормална (σ од неговата историја); асистенции/скокови/тројки ~ Poisson или negative binomial → P(НАД линија), P(ПОД линија).
5. **Калибрација:** isotonic regression од архивата (p_model → реален погодок), одделно по лига и пазар кога има ≥50 избори; до тогаш фиксна корекција (Евролига −8 pp).
6. **Пазар:** отстрани маржа (de-vig) од квотите на Mozzart → p_pazar. Предност = p_model_калибриран − p_pazar.
7. **Филтри (правила од искуство — види 5).**
8. **Тикет:** 2–3 избори, различни натпревари, без корелирани/спротивни; прикажи квота наспроти вистинска шанса.
9. **Улог:** ¼ Kelly, капа 2% од банката по избор, 3% по тикет (PROCES §5). Минимум EV ≥ +4%.

## 5. ПРАВИЛА ОД ИСКУСТВО (кодирај ги како филтри, со ознака кое правило го одбило изборот)
1. Логови секогаш сортирани по датум (грешка 27.10: зедени колата 1–5 наместо последните).
2. Спојување играч = презиме + иницијал + ист тим (грешка 16.10: Carsen ≠ Kessler Edwards).
3. Ново отсуство носи предност; старо = веќе во просеците.
4. Никогаш ПОД поени кај **првиот стрелец** на осакатен тим (Miller 34 п).
5. Асистенции ПОД само кај **не-главен** носител на топка и само ако линијата е над неговата реална улога (Giannis 11 ast).
6. Поени НАД: само ако проекцијата е ≥20% над линијата, нема blowout ризик; макс. 1 НАД поени по тикет.
7. Тотал ПОД: само кога двата тима се бавни/одбранбени и лани и сега (не по 3 натпревари).
8. Blowout: ПОД кај стартерите на фаворитот; **НЕ** ПОД кај бековите на губитникот.
9. Никогаш два играчи од ист тим во спротивни насоки на ист тикет.
10. ≥4 фаули на 36 мин → НАД поени само со голема маргина.
11. Проекција само 3–5 поени од линијата → предложи докупена линија.
12. Против тим со серија 5+ победи → без + хендикеп само по сезонски просек.
13. Играчот мора да има очекувани ≥20 минути (Евролига/Еврокуп) / ≥24 (NBA).
14. Еврокуп: максимум 2 избори по вечер додека не се стигнат 30 избори.
15. Ако модел и експертско мислење (рачно внесено) се караат → не во тикет.
16. Линијата мора да постои на Mozzart во моментот на пуштање.

| 5 | Играчки модел (минути, USG/AST%/REB%, пренасочување, распределби) | за секој играч: очекување + распределба; backtest на минати натпревари |

**Пазарот како аларм:** ако p_model − p_pazar > 15 pp → изборот се означува `ПРОВЕРИ_ПОДАТОЦИ` и не оди во тикет додека рачно не се потврди (грешка 16.10: 84% наспроти 50% = погрешен играч).
**Познато од архивата:** NBA поени НАД 7/20 (35%) — линиите на ѕвездите се надуени од публиката → НАД поени бара поголема предност.

## 9. ТЕХНИЧКИ ПРАВИЛА
- Структура: `scrapers/` (само влечење, без логика) · `model/` (само пресметки, без мрежа) · `archive/` · `reports/` · `data/raw/` · `config/` · `tests/`.
