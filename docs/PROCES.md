## 0. МИСИЈА И РЕАЛНОСТ

**Цел:** точни веројатности → избори со позитивна очекувана вредност → **долгорочно да ја победиме кладилницата** → постојано подобрување.

**Реалноста (без лажење себеси):**
- Кладилницата не „лаже“: нејзината линија е проценка на пазарот + маржа (Mozzart ~5% на главна линија, ~8% на докупена). Кај главните пазари (NBA хендикеп/тотал) таа линија е една од најточните прогнози што постојат.
- За да се добива на квота 1.90 треба погодок **над 52.6%** — секогаш, долгорочно. Повеќето играчи губат.
- Предноста е **мала и тесна**: ја бараме таму каде пазарот е бавен или пристрасен (§7), не насекаде.
- Една вечер не значи ништо. 20 избори не значат многу. **Заклучоци само од доволен примерок** (§2).
- Секој одговор е веројатност, никогаш „сигурно“. Не користиме „LOCK“, „сигурица“.

**Принцип:** Python пресметува (ист влез = ист излез) · Claude објаснува и проверува · Томе одлучува и уплаќа. Ништо не се уплаќа автоматски.

## 1. ПРАГ НА ИСПЛАТЛИВОСТ (break-even)
`потребен погодок = 1 / квота`
| Квота | Потребно | | Квота | Потребно |
|---|---|---|---|---|
| 1.50 | 66.7% | | 2.00 | 50.0% |
| 1.65 | 60.6% | | 2.20 | 45.5% |
| 1.75 | 57.1% | | 2.50 | 40.0% |
| 1.85 | 54.1% | | 3.00 | 33.3% |
| 1.90 | 52.6% | | 3.42 (тикет 2×1.85) | 29.2% |

**Очекувана вредност (EV):** `EV = p × квота − 1`. Играме само кога EV > 0 **по калибрација**. Минимум `EV ≥ +4%` (маргина за грешка во моделот).

## 2. КАКО МЕРИМЕ ДАЛИ СМЕ ДОБРИ (метрики)
| Метрика | Што е (едноставно) | Зошто е важна | Цел |
|---|---|---|---|
| **Погодок наспроти очекувано** | % погодени наспроти просекот на нашите p | дали сме прецизни | разлика < 3 pp |
| **Калибрација** | кога велиме 65%, дали паѓа ~65%? (по нивоа 55–60/60–65/65–70/70+) | „нашиот 65% мора да значи 65%“ | секое ниво ±5 pp |
| **Brier score** | просек од (p − исход)² — помало = подобро | една бројка за точноста на веројатностите | < 0.24 (подобро од 50/50 = 0.25) |
| **Log loss** | казнува многу кога сме сигурни и грешиме | ја казнува прекумерната самоувереност | надолу низ време |
| **ROI модел** | профит / улог, рамен улог (1 единица), сите избори со **вистинска проверена** квота | дали моделот бира добро, независно од тоа што е уплатено | > 0 по 200+ избори |
| **ROI уплатено** | профит / уплатено, само тоа што Томе **навистина** го уплатил (`uplata`) | вистинските пари | > 0 по 200+ избори |
| **CLV (closing line value)** | дали нашата квота беше подобра од квотата пред почеток | **најдобриот ран показател** дека имаме вистинска предност (погодокот е шум, CLV помалку) | позитивен CLV на > 55% од изборите |

**Примерок — кога смееме да заклучиме:**
- < 30 избори → само „следи“, без заклучок.
- 30–100 → насока (интервалот на доверба е ±10–15 pp!).
- 100+ по пазар → вистински заклучок.
- Пример: 13/16 (81%) за асистенции ПОД звучи одлично, но 95% интервал е ~57–93% → силен сигнал, не доказ.

Секој чекор: **кој го прави** (🐍 Python / 🔎 LLM истражувачи / 🤖 Claude / 👤 Томе) и **што ако не успее**.

**Тајминг (важи за сите лиги, од 29.10.2026):** работиме во **ЕДНА главна сесија, 3–6 часа пред првиот натпревар во вечерта** — анализа на сите натпревари одеднаш и уплата веднаш. **Нема задолжителна проверка „1 час пред“.** Затоа:

## 5. УЛОГ (bankroll) — дисциплина
- **Банка** = посебна сума наменета само за ова (што може да се изгуби без проблем).
- **Kelly критериум** (формула за оптимален улог): `f = (p × квота − 1) / (квота − 1)`. Целосен Kelly е преризичен → користиме **¼ Kelly**, максимум **2% од банката** по избор, **3%** по тикет.
- Пример: p = 0.60, квота 1.90 → f = (1.14 − 1)/0.90 = 15.6% → ¼ = 3.9% → капа **2%**.
- Никогаш не „брка загуба“ (поголем улог после лоша вечер). Никогаш тикет со 5+ избори како главен улог (шансата паѓа под 15%).
- Ова е алатка за проценка на веројатност, не финансиски совет; одлуката и ризикот се на Томе.

### 6.2 Секоја недела (`python main.py stats --nedela`)
- Калибрација по лига × пазар × ниво; Brier; CLV; ROI.
- Кои правила „спасија“ (одбиени што паднаа) и кои „чинеа“ (одбиени што поминаа).
- Ажурирај `PLAN.md` → Дневник.

### 6.3 Животен циклус на правило
`ПАРАМЕТАР-КАНДИДАТ` (1–9 случаи, или нетестиран) → `СЛЕДИ` (10–29: само спушта доверба) → **`ПОТВРДЕН`** (30+ и јасно подобро од без него, или backtest вон примерок подобар) → **`ОТФРЛЕН`** (backtest не покажа подобрување, или престанал да работи). *(29.10: „хипотеза“ → „параметар-кандидат“; „правило/укинато“ → „потврден/отфрлен“.)*
Секое правило во `config/pravila.yaml`: име, опис, статус, n, погодок со/без, датум, извор (кој случај).
**Никогаш ново правило од 1–2 случаи** (лекција 21.10: повлековме 3 избори поради една вест — сите 3 поминаа).

### 6.4 Промена на модел — само научно
1. Идеја → 2. backtest на архивата + минати натпревари (податоци што моделот не ги видел) → 3. споредба стар vs нов (Brier, калибрација) → 4. нов работи „во сенка“ (shadow) ≥ 50 избори → 5. дури тогаш замена, со нова `verzija_model`.
Никогаш не менувај запишан `p_model` по натпревар. Внимавај на **overfitting** (модел што „ја памти“ историјата наместо да ја разбира) — помалку параметри, повеќе податоци.

### 6.5 Хигиена на податоци
Без дупликати (ист датум+натпревар+играч+пазар) · унифицирани вредности (над/под, не over/poveke/nad) · резултатот како број · празен p_model = не се смета во статистиката.

## 11. РЕЧНИК (кратко)
- **Поседи / темпо (pace):** број напади по натпревар. Повеќе поседи = повеќе поени за сите.
- **ORtg / DRtg:** поени дадени/примени на 100 поседи — ефикасност без влијание на темпото.
- **Four Factors:** eFG% (шут со тројките вреднувани повеќе), TOV% (изгубени топки), OREB% (скокови во напад), FT Rate (слободни фрлања по шут).
- **DvP (Defense vs Position):** колку тимот пушта на секоја позиција наспроти лигата.
- **USG% (usage):** % од нападите на тимот што завршуваат кај играчот (шут, изгубена топка, слободни).
- **AST% / REB%:** % од соиграчките кошеви што ги асистирал / % од достапните скокови што ги фатил.
- **On/off:** како игра тимот (или играчот) кога некој е на терен наспроти кога не е.
- **Shrinkage:** намалување на ефект од мал примерок кон просекот (4 натпревари лажат).
- **Распределба (нормална / негативна биномна):** математички облик на можните исходи околу очекувањето; од неа се добива P(НАД линија).
- **De-vig:** вадење на маржата од квотите → „фер“ веројатност на пазарот.
- **Калибрација (isotonic):** поправка на нашите проценти според тоа колку реално погодувале.
- **EV:** очекувана добивка по уплатен денар.
- **CLV:** дали сме играле подобра квота од онаа пред почеток — знак на вистинска предност.
- **Kelly:** формула за големина на улогот според предноста; користиме ¼.
- **Backtest:** моделот „предвидува“ минати натпревари за да видиме колку би погодил.
- **Overfitting:** модел што ја „памети“ историјата наместо да ја разбира — добар на минатото, лош на иднината.
- **Blowout:** натпревар со голема разлика → ѕвездите седат.
